CrewAI 기반 Agent 설계

1. TrendingScraperCrew

  • 4개 스크래핑 Agent: 나무뉴스, 시그널, X, 구글 트렌드
  • 정리 Agent: 수집된 데이터 구조화
  • 교차 검증 Agent: 키워드 정규화 및 상위 5개 선별
  • 설명 Agent: 각 트렌드의 배경 설명 생성

2. MemeDataGeneratorCrew

  • 콘텐츠 생성: 토큰명, 심볼, 설명문 작성
  • 문화적 번역: 한국 맥락을 외국인이 이해할 수 있게 변환
  • 토크노믹스 설계: 재미있는 기능과 경고문 포함

3. WebsiteGeneratorCrew (진행중)

  • 디자인 결정: 토큰 성격에 맞는 웹사이트 스타일 선택
  • 구조화: 히어로 섹션, 토크노믹스, 로드맵 자동 생성

"Agent에게 너무 많은 일을 시키면 일관성이 떨어진다"
→ Task 단일화, 구체적 명령어, 예외사항 명시 필요

기술적 도전과제 상세

1. 프롬프트 엔지니어링의 복잡성

  • 문제: Agent에게 너무 많은 일을 시키면 일관성 떨어짐
  • 해결: Task 단일화, 구체적 명령어, 예외사항 명시
  • 학습: "80/20 법칙" - Agent 설계 20%, Task 디테일 80%

2. 할루시네이션과 정확성

  • 문제: AI가 잘못된 정보나 과장된 내용 생성
  • 해결: 다중 소스 교차 검증, 구조화된 출력 포맷
  • 현재 상태: 여전히 완벽하지 않음, 사람의 최종 검토 필요

3. 실시간 처리와 안정성

  • 문제: 간헐적 원인불명 에러, 단일 사용자만 처리 가능
  • 해결 시도: 비동기 처리, 에러 핸들링 강화
  • 향후 계획: Message Queue 도입, 로드밸런싱
